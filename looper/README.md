# Looper

マイクの音をトラックに重ねて録っていく、ブラウザで動くルーパー。iPhone の Safari で使うことを想定している。

- トラックを増やしながら 1 本ずつ録音する。録音中はほかのトラックが同時に鳴る
- トラックごとにミュートとソロを切り替えられる
- シークバーか波形をタップして位置を動かし、そこから再生・録音できる
- ループをオンにすると、最初に録った長さで繰り返す。2 本目以降の録音は一周で自動的に終わる
- 入力マイクを選べる
- 聞こえているトラックをまとめて 1 本の WAV に書き出せる
- ホーム画面に追加すると、オフラインでも開ける (PWA)

## 作り

- `src/engine.ts` — 再生と録音の本体。AudioWorklet の中で動き、1 サンプルずつ同じ位置を進めるので、トラック同士がずれない
- `worklets/looper.ts` — `engine.ts` を AudioWorklet に載せる包み
- `src/audio.ts` — AudioContext とマイクをつなぐ
- `src/main.ts` — 画面

遅延を減らすために、`latencyHint: "interactive"` で AudioContext を作り、マイクはエコー除去・ノイズ抑制・自動音量をすべて切って開く。
それでも残る「音が出てから、合わせた演奏がマイクに届くまで」の遅れは、録音を書き込む位置を手前にずらして打ち消す (設定の「録音の遅延補正」)。
ブラウザの申告から見積もった値が初期値で、スピーカーから出した音をマイクで拾って実測することもできる。
