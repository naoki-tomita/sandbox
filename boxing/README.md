# ボクシング雑誌バックナンバー相場調査（1995–2001）

対象は月刊の 2 誌。いずれも対象期間中は毎月刊行されていたので、
**1995年1月号〜2001年12月号 = 各84号、合計168号** が調査単位になる。

| 誌名 | 発行元 | 対象期間の刊行 |
|---|---|---|
| ワールドボクシング | 日本スポーツ出版社 | 月刊（1982年4月創刊 〜 2006年10月号で休刊） |
| ボクシング・マガジン | ベースボール・マガジン社 | 月刊（1956年創刊 〜 2022年8月号で休刊） |

---

## 1. どう調べるか

### 1-1. まず「価値」の定義を決める

ここを曖昧にしたまま数字を集めると、後で足し引きできない CSV ができる。
価格には性質の違う 3 種類があり、同じ号でも **買取 < 落札 < 店頭売価** の順に開く。

| 種類 | 意味 | 主な入手先 |
|---|---|---|
| **成約価格 (sold)** | 実際に売れた値段。「今いくらで換金できるか」に最も近い | ヤフオク落札相場、メルカリSOLD、オークファン |
| **売り希望価格 (asking)** | 出品中・在庫の提示値。売れ残りを含むので上振れする | 駿河屋、日本の古本屋、闘道館、Amazonマーケットプレイス |
| **買取価格 (buyback)** | 業者の仕入値。実売の 3〜5 割程度 | 駿河屋、ブックオフ、闘道館 |

**推奨: 成約価格を主軸**にする。売り希望価格しか取れない号は係数を掛けて落とす
（本リポジトリの既定は 0.7）。この 2 つを混ぜて平均すると相場が体系的に高く出る。

### 1-2. 情報源の優先順位

1. **ヤフオク 落札相場** — 実売データ。無料。ただし直近 4〜6 か月分しか残らない
2. **オークファン** — 落札履歴を長期にさかのぼれる。無料会員は範囲が限られる
3. **メルカリ SOLD** — 実売データ。JavaScript 描画なので Playwright が要る
4. **駿河屋 / 日本の古本屋 / 闘道館** — 在庫の売価。号指定で検索しやすく、状態表記が細かい。
   特に闘道館は格闘技専門で、増刊まで型番管理されている
5. **Amazon マーケットプレイス** — 出品者価格。極端な吊り値が混ざるので参考程度

> 相場は 1 号あたり数百円〜数千円のレンジで、**1 か所の 1 件では決まらない**。
> 最低でも「実売系 1 つ + 在庫系 1 つ」を突き合わせる。

### 1-3. 検索のかけ方 — 1 号ずつではなく、誌名で 1 回

素朴にやると「誌名 + 1997年8月号」で 168 回検索することになるが、**誌名だけで
1 回検索してページ送りで全件を辿り、あとから各商品タイトルの「◯年◯月号」を
読んで号に割り当てる**ほうがよい。

- リクエスト数が桁違いに少ない（駿河屋なら数ページで全期間ぶんが取れる）
- 「1997年8月号」と書かずに「'97/8」と書いてある出品も拾える
- 対象期間外の号も一緒に見えるので、相場の全体像がつかめる

駿河屋の場合、`ck=true&inStock=On` を付けると**在庫ありと品切れの両方**が返る。
品切れ品に付いている価格も「最後に付いていた売値」として意味があるので、
在庫状況を別カラムに記録したうえで拾い、推定時の重みを落とす。

```
https://www.suruga-ya.jp/search?category=&search_word=ワールドボクシング&ck=true&inStock=On
```

ページ送りに対応していないサイト（オークファン、メルカリ）だけ、
1 号ずつ検索する `--mode issue` を使う。

### 1-4. 手順

1. 168 号の台帳を作る（→ `data/issues.csv`。各号の各サイト検索URLが入っている）
2. サイトを巡回して「1 出品 = 1 行」で生データを貯める（→ `data/observations.csv`）
3. 号ごとに集計して推定値を出す（→ `data/valuation.csv`）
4. 高値の外れ値になった号を目視で確認し、その号の表紙・特集を記録する

生データと推定を分けておくのが要点。推定ロジックを変えても再クロールが要らない。

## 2. 落とし穴（ここで数字が壊れる）

| 罠 | 症状 | 対策 |
|---|---|---|
| **まとめ売り** | 「1990年代 まとめて75冊」が1件として混入し、単価が数千円に化ける | 冊数を抜いて 1 冊単価に割る。単品の成約がある号では推定に混ぜない |
| **切り抜き・複製** | 「表紙のみ」「切り抜き」が本誌と同列に並ぶ | タイトルで除外（`parse.py: EXCLUDE_RE`） |
| **号の取り違え** | 検索が誌名だけの緩い一致を返し、別の号の価格が混ざる | タイトルに発行年と月の両方があるか検証（`title_matches_issue`） |
| **表記ゆれ** | 「ワールド・ボクシング」「WORLD BOXING」で別々にヒットする | エイリアスを OR 展開（`issues.py: aliases`） |
| **増刊号** | 通常号の数倍。混ぜると平均が跳ねる | 別枠で集計。刊行が不定なので台帳には入れず、収集結果から拾う |
| **送料** | 「送料500円」を商品価格として拾う | 同一ブロック内の複数価格は最小値を採る |
| **1円落札** | 開始1円で入札が入らず終了した回が混ざる | 中央値を使う（平均は使わない）＋上下 10% をトリム |
| **品切れの売価** | いつ付いた値段か分からないものを現在の相場として扱う | `stock` カラムに記録し、推定時の係数を在庫ありより下げる |

## 3. 何が値段を決めるか

同じ雑誌でも号によって数倍の差が出る。効くのは概ねこの順。

1. **表紙・巻頭特集の選手** — 圧倒的に最大要因
2. **通常号か増刊号か** — 増刊は 2〜3 倍（実測アンカーで 2,200〜2,750 円）
3. **状態** — 美品／並／日焼け・書き込みで 2 倍前後は動く
4. **付録・ポスターの有無**

対象期間（1995–2001）で値が付きやすいテーマ **（仮説。要検証）**:
辰吉丈一郎の各世界戦、マイク・タイソンの復帰〜ホリフィールド 2 戦
（1997年6月の反則失格試合は特に）、デラホーヤ／ロイ・ジョーンズJr、
畑山隆則・坂本博之ら国内人気選手のタイトル戦。

> **号ずれに注意**: 月刊誌は試合から 1〜2 か月遅れて誌面に出る。
> 6 月の試合は「8 月号」（7 月中旬発売）に載るのが普通で、「6 月号」ではない。
> イベントから号を逆算するときは必ず現物の目次で確認する。

なお、この仮説を先に信じ込む必要はない。**収集結果で高値の外れ値になった号を
後から見に行けば、どの号が効いているかはデータ側から分かる。**

## 4. このリポジトリの使い方

```bash
pip install -r requirements.txt

# 1) 168号の台帳を作る（各サイトの検索URL入り）
python3 src/gen_issues.py -o data/issues.csv

# 2) まず何を叩くのか確認する（通信しない）
python3 src/collect.py --dry-run

# 3) 試運転。パーサが検索結果ページの構造に合っているか確かめる
python3 src/collect.py --sources surugaya --max-pages 1 --keep-unmatched
#    0 件なら parse.py の SITE_SELECTORS を実際の DOM に合わせる

# 4) 本番収集。誌名で1回検索してページ送りで辿る
python3 src/collect.py --sources surugaya,yahoo_closed --max-pages 30 --delay 3

# 5) ページ送り非対応のサイトは1号ずつ
python3 src/collect.py --mode issue --sources aucfan --delay 3

# 6) 集計して推定値を出す
python3 src/estimate.py -i data/observations.csv -o data/valuation.csv
```

`collect.py` は取得した HTML を `.cache/` に保存する。再実行しても
再取得しないので、パーサを直しながら何度でも回せる。

### 出力 CSV

- **`data/issues.csv`** — 号マスタ。168 行。各号 × 7 サイトの検索 URL。
  スクリプトを使わず手作業で調べる場合も、この URL を順に開けば台帳として使える
- **`data/observations.csv`** — 生データ。1 出品 1 行。
  タイトル・価格・状態・在庫状況・まとめ売り判定・増刊判定・出典 URL
- **`data/valuation.csv`** — 最終成果物。1 号 1 行。
  `estimated_value_jpy` と、その根拠（`basis`）・信頼度（`confidence`）付き
- **`data/price_benchmarks.csv`** — 既知の相場アンカー（下記）

推定値は次の優先順位で決まる。上ほど信頼できる。

| 順 | 根拠 | 係数 | confidence |
|---|---|---|---|
| 1 | 単品の落札価格の中央値（3 件以上） | 1.0 | 高 |
| 2 | 同上（1〜2 件） | 1.0 | 中 |
| 3 | 在庫ありの希望価格 | 0.7 | 中 |
| 4 | 品切れの希望価格 | 0.6 | 低 |
| 5 | まとめ売りの 1 冊単価 | 1.0 | 低 |
| 6 | その誌の全体中央値で補完 | — | 参考値 |

**`参考値` の行はその号を調べた結果ではない**ので、そのまま数字として扱わないこと。

増刊は通常号の 2〜3 倍になるため推定には一切使わず、`n_extra` /
`extra_median_jpy` に退避してある。

### サイト仕様の確認が必要な箇所

`src/sources.py` の各 `Source` に `verified`（URL 形式を実 URL と照合済みか）と
`paged`（ページ送り対応か）のフラグがある。

- 照合済み: ヤフオク（落札相場・出品中）、オークファン、メルカリ、駿河屋の 1 ページ目
- **未確認**: `kosho`（日本の古本屋）、`toudoukan`（闘道館）の検索 URL 形式、
  および駿河屋・ヤフオクの**ページ送りパラメータ**

未確認のものは `--dry-run` で 1 件ブラウザに貼って、期待する結果が出ることを
確かめてから本番に使うこと。特にページ送りは、パラメータが効いていないと
同じ 1 ページ目を何度も取ることになる。collect.py は「新規 0 件」を検出したら
その時点で打ち切るので暴走はしないが、`p2: 新規0件` がいきなり出たら
ページ送りが効いていないと考えてよい。

オークファンは検索語を EUC-JP の 16 進で埋める独特の形式で、`sources.py` が対応している。

## 5. 現時点で分かっている相場アンカー

`data/price_benchmarks.csv` に出典 URL 付きで格納。要点:

- **通常号は数百円台**。ワールドボクシング 1990年11月号が古書店在庫で 440 円、
  1982年7月号で 770 円
- **ヤフオクでの個別号の平均落札は 800 円前後**（ボクシング・マガジン）。
  1 円〜1,000 円程度に広く分布する
- **増刊号は 2,200〜2,750 円** と通常号より一段高い
- 「ボクシング雑誌」全体の平均落札 1,700 円という数字はまとめ売りを含むため、
  個別号の相場としては使えない

つまり **1995–2001 の通常号は、状態が普通なら 1 冊 300〜1,000 円が中心帯**で、
話題性の高い号と増刊だけが数千円に跳ねる、という構図を想定してよい。

> これらは検索結果のスニペット由来で、個々の出品ページを直接確認したものではない。
> 収集スクリプトを回して実データで置き換えること。
