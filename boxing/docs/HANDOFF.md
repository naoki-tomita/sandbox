# 引き継ぎメモ

`boxing/` を別セッションで引き継ぐための状態まとめ。作業手順そのものは
`boxing/README.md` にあるので、まずそちらを読むこと。ここには README に
書いていない「経緯」と「次にやること」だけを残す。

## 何をしようとしているか

ワールドボクシング / ボクシング・マガジンの **1995年1月号〜2001年12月号**
（各84号、計168号）が、いま中古市場でいくらの価値になっているかを調べ、
CSV に落とす。

## 決まっていること

- **価格は3種類を分けて扱う** — 成約価格 / 売り希望価格 / 買取価格。
  混ぜると相場が体系的に高く出る。詳細は README の 1-1
- **検索は誌名で1回かけてページ送りで辿る**（`--mode broad`）。
  1号ずつ168回叩くのではない。README の 1-3
- **駿河屋の検索URLは `ck=true&inStock=On` を付ける。**
  これで在庫あり＋品切れの両方が返る（ユーザー確認済み）
- **品切れ品の価格も収集する。** ただし「最後に付いていた売値」で時点が
  古い可能性があるため、`stock` カラムで区別し推定係数を 0.7 → 0.6 に下げる
- **増刊は推定に使わない。** 通常号の2〜3倍あり、混ぜると相場が跳ねる。
  `n_extra` / `extra_median_jpy` に退避してある

## 環境の制約（重要）

**Claude Code on the web のセッションからは中古市場サイトに一切アクセス
できない。** 組織のエグレスポリシーにより、駿河屋・ヤフオク・メルカリ・
日本の古本屋・闘道館・Amazon すべて CONNECT が 403 で弾かれる。
`curl` も `WebFetch` も同じ関門を通るため回避できない。到達できるのは
GitHub とパッケージレジストリ（pypi 等）のみ。

生きているのは `WebSearch` だけで、これは検索結果のスニペットしか返さない。
`data/price_benchmarks.csv` の数字はこの経路で得たもので、個々の出品ページを
直接確認したものではない。

したがって **実際の価格収集はユーザーのローカル環境で実行する前提**。
これはユーザーと合意済み。

## 次にやること

1. ユーザーのローカルで試運転する

   ```bash
   cd boxing && pip install -r requirements.txt
   python3 src/collect.py --dry-run --sources surugaya
   python3 src/collect.py --sources surugaya --max-pages 1 --keep-unmatched
   ```

2. 抽出が0件、またはページ送りが効いていなければ、実際の検索結果ページの
   HTML を見て `parse.py` の `SITE_SELECTORS` と `sources.py` の
   ページ送りパラメータを直す
3. 本番収集 → `estimate.py` で集計
4. 高値の外れ値になった号を目視で確認し、表紙・特集を `notes` に記録する。
   README 3章の「値段を決めるのは表紙の選手」という仮説を、ここで
   データ側から裏取りできる

## 相場の見当

通常号 440〜800円、ヤフオク個別号の平均落札800円前後（1円〜1,000円に広く分布）、
増刊 2,200〜2,750円。**1995–2001の通常号は状態が普通なら1冊300〜1,000円が中心帯**
で、話題性の高い号と増刊だけが数千円に跳ねる、という構図を想定してよい。
出典は `data/price_benchmarks.csv` に URL 付きで入っている。
